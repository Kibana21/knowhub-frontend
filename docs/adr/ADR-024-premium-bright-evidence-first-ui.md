# ADR-024 — Premium bright evidence-first UI design language

- **Status:** Accepted
- **Scope:** frontend
- **Origin:** master blueprint §82
- **Supersedes:** —
- **Superseded by:** —

## Decision

Enterprise V1 uses a premium bright evidence-first UI design language.

## Rationale / consequence

Light surfaces, crisp typography, restrained accents and task-oriented workspaces improve enterprise adoption without turning KnowHub into a generic chat/admin console.
